## 0. 教材への示唆

### 0.1 調査で分かったこと（要点）
1. **共通テストは文法を単独で問わない**（発音・アクセント・語句整序の単独問題なし）。リーディングは80分・100点、令和7年度から大問8題・マーク44、選択肢を含め約5,600語。CEFR A1〜B1 が目安（S1, S2, S4）。→ 関係詞は「長い名詞句を前から正確に読む力」「言い換えの判定」「推敲（第4問）で文を結合・補足する力」として間接的に問われる。
2. **GMARCH は文法を直接問う形式が多い**。各大学の「出題の意図」（2026年度）で確認できた形式は、4択空所補充、正誤指摘（青学全学部・立教・中央・学習院）、語句整序（青学経済・中央法/経済・法政）、和訳（青学・立教・中央・学習院）、和文英訳・穴埋め英作文（中央法・学習院・立教）（S11〜S26）。法政T日程や一部A方式のように、文法を長文の中だけで問う方式もある。
3. 関係詞で入試の判断ポイントになるのは、**前置詞＋関係代名詞と関係副詞の区別（後ろが完全か不完全か）**、**what と that/which の区別**、**関係代名詞 that と接続詞 that の区別**、**非制限用法（that 不可・前文全体を受ける which）**、**複合関係詞と譲歩**、**連鎖関係詞節**、**省略**（第3節）。単元別の出題頻度は一次資料では数値化できず【推定】。
4. 日本人学習者の関係節の誤りは「関係節内の構造の誤り」（be 動詞の脱落など）が最多で、前置詞の脱落・再述代名詞・関係代名詞の選択誤りが続く（S31）。
5. 時間・配点を公式資料で確認できたのは、明治の学部別入試（60〜80分、100〜200点、S10）と学習院（90分、S26）のみ。青学・立教・中央・法政は**未確認**。

### 0.3 ★の基準（要約。詳細は第4節）【設計判断】
- **★ 共通テスト水準**：関係詞を含む文を前から読んで正しく理解できる。who/which/that、目的格の省略、whose、基本の where/when、what の基本、非制限用法の読み取り。1文15語程度、CEFR-J A1〜A2。
- **★★ GMARCH 標準**：4択・正誤・整序で正しい形を選べる・作れる。前置詞＋関係代名詞と関係副詞、what と that、that の二用法、非制限の which、数量詞＋of which、複合関係詞、連鎖関係詞節、省略、一致。1文25語程度、CEFR-J B1 まで。
- **★★★ 発展**：as/than/but の擬似関係代名詞、関係形容詞、A is to B what C is to D、関係詞節の外置、二重限定、複雑な文の和訳。1文35語程度、CEFR-J B2 まで。

### 1.3 文法（関係詞）との関係
- 文法単独問題はない。関係詞は「読解の精度」として間接的に問われる：言い換え選択肢の判定、複数箇所からの情報統合、長い名詞句の把握（S1、S4）。
- 第4問（推敲）は「文全体の趣旨に合うように英文を修正」する形式（S4）で、文の結合・情報の補足を扱うため、関係詞節で情報を追加・整理する力が最も直接に関わる大問と考えられる【推定】。
- 処理速度：80分で約5,600語。J PREP は設問・図表込みで毎分約150語の処理が必要と分析（S6、二次）。関係詞節を「戻り読み」せずに前から処理する練習が教材の★レベルの中心課題になる。
- 語彙：J PREP は語彙水準の目安を「英検準2級プラスと準1級の中間」とし、A1語の割合が減りA2以上が増加と分析（S6、二次）。

## 3. 関係詞の頻出パターン・形式・典型的誤り

### 3.1 前提：学習指導要領上の位置（一次）
- 中学校：関係代名詞は **主格の that / which / who、目的格の that / which の制限的用法** のみ（S30）。
- 高校（英語コミュニケーションⅠ〜）：文法事項に「関係代名詞の用法」「関係副詞の用法」（S30）。→ **whose、whom、前置詞＋関係代名詞、関係副詞、what、非制限用法、複合関係詞などは高校で扱う事項**。共通テストの出題範囲は英コミⅠ・Ⅱと論理・表現Ⅰ（S1）なので、これらも範囲内。
- 共通テストは文法単独問題を出さないため、関係詞は「読めるか」で問われる。GMARCH は空所補充・正誤・整序・和訳で「使えるか・見抜けるか」まで問う（2.2）。

### 3.2 頻出パターン一覧

### 3.4 受験生の典型的な誤り
一次的な実証データ（学習者コーパス研究）と、指導上よく知られた誤り（【推定】）を分ける。

**(a) 学習者コーパス研究（S31：Takahashi 2018, 『英語コーパス研究』25号）**
- 中高生作文コーパス JEFLL と発話コーパス NICT JLE を CEFR A1〜B2 別に分析。関係節を含む文の誤り率は JEFLL 22.47%、NICT JLE 12.65%。
- 最多は「関係節内の構造の誤り」（全誤りの半分以上）。内訳は語順・構造の誤り、関係代名詞の後の **be 動詞の脱落**（JEFLL で構造誤りの35%）、関係代名詞＋be を決まった形と思い込む誤り、日本語の直訳による不自然な関係節、文が完結しない誤り。
- 他の類型：先行詞の欠落、**前置詞の脱落**（JEFLL では B2 で増加。前置詞を伴う複雑な構造を使い始めると前置詞を落とす）、**再述代名詞**（関係節内に it などが残る）、**関係代名詞の選択誤り**（whose の代わりに which など。レベルが上がると減少）。
- 関係節の使用頻度は CEFR レベルとともに上がり、特に A→B1 の境界で明確に増える。著者は、A から B へ上がる段階で関係節が特に重要としている。

**(b) 文法性判断の研究（S32：Hayashi 2018, LET Kyushu-Okinawa Bulletin 18）**
- 日本の大学生70名。関係代名詞が欠けた主語関係節（主格の省略＝非文）の判断が目的語関係節より難しかった。関係代名詞の存在が文法知識を働かせる手がかりになる可能性。→ 「主格は省略できない」を正誤問題で練習する根拠になる。

**(c) 入試形式で起きやすい誤り【推定：指導経験上よく知られた誤りとして整理。数値の裏付けなし】**
1. 先行詞が場所・時の名詞なら必ず where / when を選ぶ（節が不完全なら which / that）。
2. 前置詞＋which の後ろに目的語の欠けた節を置く。
3. what の前に先行詞を置く（the thing what）。
4. 非制限用法に that を使う、コンマの後に that を選ぶ。
5. 関係詞節の中に代名詞を残す（再述代名詞）。整序でも同じ。
6. 連鎖関係詞節で I think の目的語と考えて whom を選ぶ。
7. however の後の語順（however hard S V）を崩す／whatever と however を取り違える。
8. 関係代名詞 that と接続詞 that（同格）の区別ができず、和訳で修飾関係を誤る。
9. 非制限の which が前の文全体を受けるのに、直前の名詞を指すと訳す。
10. 関係詞節内の動詞の数を先行詞に一致させない（特に one of the … who の後）。

### 6.3 シリーズ構成への示唆【設計判断】
- GMARCH で「高」かつ共テでも読解に効く単元（不定詞・分詞・**関係詞**・比較・仮定法・動詞の語法・前置詞）を先に出す。関係詞を第1冊にするのは妥当。
- 「語法（動詞・名詞・形容詞）」「前置詞」「会話表現」は GMARCH の空所補充・正誤で点になるので、文法書とは別に問題演習型の冊子にする。
- 共テの最重要は長文読解・情報処理型読解なので、各文法冊の最後に「共テ型の短い読解（チャット、案内、推敲）」を1セット置く。
