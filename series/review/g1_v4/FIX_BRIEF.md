## 方針（編集長が決めた）
1. **正解が成り立たない問題**（例題152・問752：歴史上の事実の had ended／had been held は正しい英文）は作り直す。点検の案のとおり、現在完了と過去の年号（has ended in 1945 など）のように、はっきり誤りになる形にする。
2. **19-1 の言い切り**は「歴史上の事実は過去形で言うのがふつう。過去完了も誤りではない」に直し、要点・根拠（問771 など）もそろえる。
3. **1語で答える問題に正解が2つ入るもの**（問680 seldom／rarely、問685 until／till、問761 the day before／the previous day、問776 had got／had gotten）は、すべて `alt` に入れる。get の過去分詞は語注を付ける。
4. **本文にない理由で選択肢を外す問題**（問736 の Because、問669 の do you think that、問701 の if、問682・696 の neither と not、問738 の It was と that の間の節）は、本文か側注に1文足して、戻り先で解けるようにする。
5. **参照の誤り**：p.420 の「単元15で見た Never have I seen …」は、単元15 にない。単元18 の本文の言い方を直す（単元15 の本文に例文を足すのでもよい）。p.407 の It was not until の参照先は、内容のある節を指す。
6. **前提チェックの戻り先**：問題の内容を教えている節（前の単元の節）を指す。単元18 の方針（元の単元に戻す）にそろえる。中学の内容で本書に説明がない場合は、その単元の第1節の「中学の復習」の側に1文を足すか、戻り先をいちばん近い節にする。
7. **表の書き方**：20-3 の要点の表の tell の行は「tell 人 that ～」のように人を省かずに書き、単元19 と食い違わないようにする。
8. **答えの書き方**：正誤の例題の答えは「②（A → B）」の形にそろえる（例題146 など）。付加疑問の訳の時制、別冊の「よくある間違い」と選択肢の対応（問674・695）も直す。
9. 中・低の指摘はすべて対応する。直さないものは理由を書く。

- 問題を作り直すときは id を変えず、why・trap も書き直す。ほかの選択肢・並べ方・下線で正しくならないかを1つずつ確かめる。
- 別解・選択肢に半角コンマを含む英文を書くときは、1行の [ … ] ではなく、行ごとの `- ` の形にする。
- 編集の後に必ず実行：`python3 series/tools/validate.py series/src/g1.yaml series/src/parts/g1_c*.yaml` → ERROR 0。組版は実行しない。
