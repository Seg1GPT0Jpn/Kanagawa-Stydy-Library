# S4 レポート（変更10問＋完全解説book 第3節 確認(3)）

正誤問題の下線は mondai.pdf の p.12, 16, 23, 30, 39, 47, 54 を画像で見て確かめた。

## 各問の答えと根拠（要約）
- 問31（p.12）：④ about that → about which。前置詞の直後に関係代名詞 that は置けない。③ の that は so ... that 構文で正しい。
- 問45（p.16）：④ when → where（または at which）。先行詞 the inn は場所で、stayed のあとに場所の副詞が欠けている。
- 問72（p.23）：④ what → that（または削除）。先行詞 the ones があるので what は使えない。② she had は目的格の省略で正しい。
- 問98（p.30）：④ that → who。コンマの後（非制限用法）に that は使えない。
- 問128（p.39）：④ whomever → whoever。whoever は節の中で needs の主語になる。
- 問154（p.47）：④ whom → who。we had heard が入りこんだ節で、関係詞は would come の主語になる。
- 問155（p.47）：③ than。more letters than we could answer（than が関係代名詞のように働く）。
- 第2問(9)（p.53）：① which。believe O to be C の O が欠けた形で、先行詞は物。
- 第3問(4)（p.54）：④ both of them → both of whom。コンマの後に節をつなぐ接続詞がないので、関係代名詞にする必要がある。
- 第4問(1)（p.55）：The watch my father bought for me no longer works.（目的格の関係代名詞を省いた形）
- 第3節 確認(3)（完全解説book p.10）：which（that でもよい。省略も可）

## 答えが2つ考えられる問題
- 第3節 確認(3)：which・that のどちらでも正解で、関係代名詞を省略することもできる。解答枠は1つで「語を答えなさい」とあるが、赤字の解答は「which／that（…省略も可）」と複数を認めている。答えの欄に which と書いた。
- 問45：直し方は where・at which・in which のどれでもよい。ただし記号を選ぶだけの問題なので、答えの記号は④の1つに決まる。
- 問72：直し方は that に替えても、削除してもよい。こちらも記号選択なので答えは1つに決まる。
- 第3問(4)：直し方は both of whom が標準。接続詞を足す and both of them も考えられるが、コンマは下線部の外なので、④だけを直すなら both of whom になる。採点で and both of them を認めるかどうかを、解説に書いておくとよい。
- 正誤問題・選択問題の残り（問31, 98, 128, 154, 155, 第2問(9)）と第4問(1)は、それぞれ答えが1つに決まる。

## 指示のあいまいさ・不足
- 第3節 確認：「［ ］に入る語を答えなさい」は1語を答える形に読めるが、答えは2語のどちらでもよく、空所に何も入れない（省略）も正解になる。「入る語をすべて答えなさい」「省略できる場合はそれも答えなさい」のように書くと、指示と解答が合う。
- 第4問の指示「文頭に来る語も小文字で示してある」は、(1) では The がかっこの外にあるので関係しない（ほかの小問のための指示）。大きな問題ではない。
- 第3問の指示「語を取り除くときは『削除』と書きなさい」は、(4) には関係しない。問題ではない。

## 解答欄の不足
- 担当の問題では見当たらない。第3問(4)には「記号」の枠と「正しい形」の行があり、「4 / both of whom」を書ける。第4問(1)の解答行も足りている。
- 確認(3)は空所が1つなので、which／that を両方書くにはせまい（ただし赤シートで確かめる確認問題なので影響は小さい）。

## ★の表示と難しさのずれ
- 問154（★★）：I think などが入りこんだ節で who／whom を見分ける問題で、本書でもっとも差がつく型の1つ。第6章のほかの同じ型の問題（問157 は ★★★）とくらべると、★★★ でもおかしくない。★★ のままでも許容範囲。
- 第4問(1)（★★）：6語を並べるだけで関係代名詞を省いた形も基本なので、★ くらいの難しさ。軽いずれ。
- そのほか（問31, 45, 72, 98, 128, 155, 第2問(9), 第3問(4)）は ★★ で妥当。

## 不自然な英文
- 担当の問題の英文に、はっきり不自然なものはない。
- 問45 の twenty years before は、過去完了と合わせて正しい。
- 問31 の the report about which Ms. Ono spoke in class は正しいが、やや硬い言い方。the report Ms. Ono talked about in class のほうが自然。
