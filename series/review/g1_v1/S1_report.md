## 2. 種類ごとのまとめ

- **答えが2つ考えられる問題**：問41・問156（高）、問157・問37（中）。問124・135・141・186 は書き方がいくつかある（低）。
- **指示のあいまいさ**：問149 の「下線部を英語にしなさい」、問30・97・149 の下線の数と語数の関係、例題の指示文がないこと。
- **解答欄の不足**：解答欄が足りなくて書けなかった問題は**なし**。ただし問149 は下線（4つ）が短く、7語の答えに見合っていない。
- **★と難しさのずれ**：問179（elect が未習なので★★でも難しい）、問185（関係詞が未習）、問162（★1つの正誤問題）。
- **説明が足りない・難しすぎる箇所**：p.48 の用語「基準の時」の余白（完了不定詞など未習の用語）、p.40–41 の主節・従属節・副詞節・名詞節、p.76 の done／doing の記号、「単元◯」と「第◯章」の混在。
- **例題を読んでも解き方が分からなかった問題**：問179（elect O C の受動態。例題36 は name で、captain の前の冠詞が分からない）。ほかの問題は、例題の手順で解けた。
- **文法の説明の誤り・非文法的な英文・和訳の誤り**：本冊を読んだ範囲では、はっきりした誤りは見つからなかった（2-3 要点表の言い切りの強さは 7 番に書いた）。ただし、これは学習者として読んだ範囲の結果で、「誤りがない」ことを確かめたわけではない。

## 3. 確認した範囲と、確認しきれなかった点

- 確認した範囲：本冊 p.1–110（第1〜5章の中学の復習・解説・確認・例題・問題・要点・確認テスト）。問1〜問203 を全部解いた。正誤問題の下線は全部、画像で番号の位置を確かめた。
