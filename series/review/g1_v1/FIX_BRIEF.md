# 修正の指示（英文法編 第1〜5章）

## 方針（編集長が決めた）
1. **正誤問題で、1か所の誤りに下線が2つに分かれているもの**（問41 の reached／at、問156 の must／snowing、例題4 の discussed／about など）は、誤りを含む部分を1つの下線にまとめるか、文を作り直して、どの下線を直しても正しくなる余地をなくす。同じ作りの問題がほかにないか、単元1〜5 の正誤問題をすべて見直す。
2. **言い切りが強すぎる説明**は、例外を具体的に書いてから規則を述べる形に直す（名詞節の will と、時刻表・決まった予定・hope の後ろの現在形、could と was able to と知覚動詞、must の義務／推量の見分け方は「目安」に下げる、など）。直した説明に合わせて、要点・根拠・よくある間違いも直す。
3. **用語の定義の例外**（名詞のかたまりの M、副詞の定義）は、第1章の定義を「例外なく使える言い方」に直す。後の単元がこの定義を参照する。
4. **超基礎の読者がつまずく点**（まだ習っていない用語を先に出さない、done・doing の書き方を最初に出てくる所で説明する、主節・従属節・副詞節・名詞節を一度に出さず段階を踏む、など）は、本文・側注を直して解消する。ほかの単元の内容を先に使う問題（動名詞・関係詞 who を使う問題など）は、その単元の範囲で解ける文に直す。
5. **戻り先・参照ページのずれ**（前提チェックの戻り先、p.30 の過去分詞の表、→ p.39 など）は、内容のある節を指すように直す（`ref` は節を複数書ける）。過去分詞の変化を確かめる表が必要なら、適切な節に置く。
6. **「単元」と「章」**：本は「単元1」の呼び方にそろえた（組版で対応済み）。本文の「第◯章」の書き方があれば「単元◯」に直す。
7. **指示の不足**：意味の誤りを選ぶ正誤問題は指示文に「文の意味から考えて」を足すか作り直す。英作の採点基準で、問題文で指定していない表現を必須にしない。例題に指示文がないものは q の最初に指示を書く。解答欄の線を4つに分けた形（＿ ＿ ＿ ＿）は使わない。
8. 中・低の指摘はすべて直す。直さないものは理由を書く。

- 問題を作り直すときは id を変えず、why・trap も書き直す。ほかの選択肢・並べ方・直し方で正しくならないかを1つずつ確かめる。4択の正解の位置は気にしなくてよい（あとで機械でならす）。
- 編集の後に必ず実行：`python3 series/tools/validate.py series/src/g1.yaml series/src/parts/g1_*.yaml` → ERROR 0（正解の位置の WARN は無視してよい。単元6〜10 のファイルが書きかけで ERROR が出る場合は、単元1〜5 だけで `python3 series/tools/validate.py series/src/g1.yaml series/src/parts/g1_c0[1-5].yaml` を実行）。組版は実行しない。
