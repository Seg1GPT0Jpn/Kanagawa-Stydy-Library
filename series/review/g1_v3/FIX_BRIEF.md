## 方針（編集長が決めた）
1. **答えが2つになる問題**（問441 など）は作り直すか選択肢を差しかえ、答えを1つにする。別解として正しいものは `alt` に入れる（問489、問524 の per、例題112、問556 など。入れないなら問題を作り直す）。
2. **1つの誤りに下線が2つかかる正誤**（問594、例題122）は、下線を1つにまとめるか文を作り直す。
3. **正しい英語を「誤り」と言い切らない**。問604 の I never will forget は「強調のときには使われるが、ふつうは will never」と書き、整序で答えが2つにならないよう作り直す。q12005（問464）は was を alt に入れ、根拠に「話し言葉では was も使う。入試の記述では were と書くのが安全」と書く。
4. **語形を変える問題に時の手がかりがないもの**（問540・563・575）は、現在だと分かる語（now・every day など）を足す。
5. **用語の誤り**：It's time we go の go を「原形」と呼ばない（過去形が基本、現在形は話し言葉で見られる、と正しく書く）。
6. **★のずれ**（倒置を書く問471・494 が★、選ぶ問475・493 が★★）をそろえる。書かせるほうを★★にする。
7. **戻り先**：前提チェック（問417・418、問580・581 など）と参照は、内容のある節を指す。
8. **言い切りが強すぎる説明**（some／any の「例外は2つ」、「前置詞は動詞で決まる」など）は、例外を書いてから規則を述べる。
9. **習っていない語・形**（S2 の指摘：問584 の sleepy、問591 の help、問496 の a pair of、問490 の such a lie、問489 の got／gotten など）は、本文・語注に足すか、問題をその単元までの範囲で解ける文に直す。
10. **単元をまたぐ重複**：例題114 と例文268 が同じ文なら、片方を差しかえる。
11. 中・低の指摘はすべて対応する。直さないものは理由を書く。「→ 単元17」などの下巻への参照は、単元16〜20 ができると自動でページになるので直さなくてよい。

- 問題を作り直すときは id を変えず、why・trap も書き直す。ほかの選択肢・並べ方・下線で正しくならないかを1つずつ確かめる。4択の正解の位置は気にしなくてよい。
- 編集の後に必ず実行：`python3 series/tools/validate.py series/src/g1.yaml series/src/parts/g1_c0*.yaml series/src/parts/g1_c1[0-5].yaml` → ERROR 0。組版は実行しない。
