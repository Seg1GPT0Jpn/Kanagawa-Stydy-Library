# 超基礎から学ぶ高校英語（かながわ教材ライブラリ）

塾に通わなくても、塾の授業と同じ流れで、大学入学共通テストと GMARCH 個別試験の水準まで自分で学べることを目指した、無料の英語教材です。印刷して、赤シートを使って学ぶ前提で作っています。

## ご利用の前に（必ずお読みください）

**この教材は AI（Claude）が作成し、自動検査と AI による点検を重ねたものです。人間の専門家（英語の教員など）による確認は、まだ受けていません。** 授業・配布・販売などに使う前に、必ず英語の専門家に内容を確認してもらってください。誤りを見つけた場合は、このリポジトリの Issues でお知らせください。

中身：例文134、例題38、問題285（節末209・章末48・模擬試験28）、要点86、索引の用語22。

### 進め方
1節ずつ、①解説を読む → ②節の中の「確認」を赤シートで隠して答える → ③例題の「解き方」を読み、同じ手順で考える → ④問題を解き、別冊で答え合わせ。間違えたら別冊の「間違えたら戻る」のページを読み直す → ⑤要点を赤シートで隠して言えるか確かめる。間違えた問題は1週間後と1か月後に解き直し、□に印を付けます。章末問題のあとは、別冊の診断表で読み直す節を確かめます。

### 印刷のしかた
- **そのまま印刷**：各 PDF を A4 で印刷します。
- **冊子にする（中綴じ）**：`dist/eg01/booklet/` の PDF を A3 用紙に**両面・短辺とじ**で印刷し、重ねて二つ折りにして中央をホチキスで留めます。左綴じです。本冊は 38 枚と厚いので、ホチキスが届かないときは、A4 版を印刷して左端を綴じてください。
- **ページ順の確認**：`dist/eg01/dummy/` はページ番号だけのダミーです。本番の前に印刷して折り、順に並ぶことを確かめてください。

### 赤シートについて
答えは赤（#FF4B00、カラーユニバーサルデザイン推奨配色セットの赤）で印刷しています。プリンタや用紙によっては赤シートで隠れにくいことがあります。最初に1枚試し刷りして、手持ちの赤シートで隠れるか確かめてください。
