# 高校英語シリーズ（かながわ教材ライブラリ）

塾に通わなくても、大学入学共通テストと GMARCH 個別試験の水準まで自分で学べることを目指した、無料の英語教材です。印刷して、赤シートを使って学ぶ前提で作っています。

## ご利用の前に（必ずお読みください）

**この教材は AI（Claude）が作成し、自動検査と AI による点検を重ねたものです。人間の専門家（英語の教員など）による確認は、まだ受けていません。** 授業・配布・販売などに使う前に、必ず英語の専門家に内容を確認してもらってください。誤りを見つけた場合は、このリポジトリの Issues でお知らせください。

### 印刷のしかた
- **そのまま印刷**：各 PDF を A4（要点まとめは A5）で印刷します。
- **冊子にする（中綴じ）**：`dist/eg01/booklet/` の PDF を、A3 用紙（要点まとめは A4 用紙）に**両面・短辺とじ**で印刷し、重ねて二つ折りにして中央をホチキスで留めます。左綴じです。
- **ページ順の確認**：`dist/eg01/dummy/` は、ページ番号だけを印刷したダミーです。本番の前に印刷して折り、1ページ目から順に並ぶことを確かめてください。

### 赤シートについて
答えは赤（#FF4B00、カラーユニバーサルデザイン推奨配色セットの赤）で印刷しています。プリンタや用紙によっては赤シートで隠れにくいことがあります。最初に1枚試し刷りして、手持ちの赤シートで隠れるか確かめてください。

## 作り方（再現・改変したい人へ）
- 唯一のデータ：`src/eg01.yaml`（本文・訳・解説・問題・答え・要点のすべて）
- 組版：`python3 tools/release.py eg01`（組む → 自動チェック → 合格したときだけ `dist/` に書き出す）
- 設計の根拠：`research/`（調査5本と出典一覧）、`design/`（設計規則・データ形式・執筆の指示）
- 点検の記録：`review/`（点検・修正・再点検のすべての報告）
