# 超基礎から学ぶ高校英語（かながわ教材ライブラリ）

塾に通わなくても、塾の授業と同じ流れで、大学入学共通テストと GMARCH 個別試験の水準まで自分で学べることを目指した、無料の英語教材です。印刷して、赤シートを使って学ぶ前提で作っています。

## ご利用の前に（必ずお読みください）

**この教材は AI（Claude）が作成し、自動検査と AI による点検を重ねたものです。人間の専門家（英語の教員など）による確認は、まだ受けていません。** 授業・配布・販売などに使う前に、必ず英語の専門家に内容を確認してもらってください。誤りを見つけた場合は、このリポジトリの Issues でお知らせください。

## 第一講【英文法編】（第1版）

高校英文法の全20単元を、★（共通テスト）と★★（GMARCH 標準）の範囲で1冊にまとめたものです。上巻・下巻のページ番号は通しです。

| ファイル | 内容 | ページ |
|---|---|---|
| `dist/g1/g1_本冊_上巻_p1-256_A4.pdf` | 単元1〜10（文型・時制・完了形・助動詞・態・不定詞・動名詞・分詞・接続詞・関係詞）、総合演習 第1回、索引（上巻） | 256 |
| `dist/g1/g1_本冊_下巻_p257-508_A4.pdf` | 単元11〜20（比較・仮定法・名詞と冠詞・代名詞・形容詞と副詞・前置詞・疑問と否定・強調・倒置・省略・挿入・話法と時制の一致・語法）、総合演習 第2〜4回、索引（上巻・下巻） | 252 |
| `dist/g1/g1_別冊_解答解説_A4.pdf` | 全942問の正解・根拠・よくある間違い・「間違えたら戻る」（本冊のページと例題の番号）。単元ごとの診断表 | 192 |

中身：例文501、例題166、問題942（前提チェック60・節末562・確認テスト200・総合演習120）、要点322、索引の用語106。

### 進め方
単元の入口の「中学の復習」と「前提チェック」で準備をしてから、各節を ①解説 → ②確認（赤シート）→ ③例題の解き方 → ④問題（別冊で答え合わせ。間違えたら「間違えたら戻る」のページへ）→ ⑤要点（赤シート）の順に進めます。単元の終わりの確認テスト（前の単元の問題も混ざる）のあとは、別冊の診断表で読み直す節を確かめます。総合演習は上巻の終わりに第1回、下巻の終わりに第2〜4回があります。

### 印刷のしかた
- **そのまま印刷**：各 PDF を A4 で印刷し、左端を綴じます（ページが多いので、パンチ穴とファイル、または製本テープが便利です）。
- **冊子にする（折丁）**：`dist/g1/booklet/` の PDF は、16ページ（A3 用紙4枚）ずつの折丁に面付けしてあります。A3 用紙に**両面・短辺とじ**で印刷し、4枚ずつ重ねて二つ折りにすると、16ページの折丁になります。折丁を順に重ねて、背を綴じてください（左綴じ）。
- **ページ順の確認**：`dist/g1/dummy/` はページ番号だけのダミーです（各ファイルの中で 1 から数えます）。本番の前に印刷して折り、順に並ぶことを確かめてください。

報告（ページ数・中身・自動チェック・点検で見つかった誤りと対応・確かめていないこと）：`review/REPORT_g1.md`

## 第1講【関係詞】（第1版）

| ファイル | 内容 | ページ |
|---|---|---|
| `dist/eg01/eg01_本冊_A4.pdf` | 6章19節。各節は「解説 → 例題（解き方の手順つき）→ 問題（書き込み式）→ 要点（赤シート）」。章末問題、模擬試験（45分・100点）と解答用紙、索引 | 152 |
| `dist/eg01/eg01_別冊_解答解説_A4.pdf` | 全285問の正解・根拠・よくある間違い・「間違えたら戻る」（本冊の解説のページと例題の番号）。章ごとの診断表 | 68 |

中身：例文134、例題38、問題285（節末209・章末48・模擬試験28）、要点86、索引の用語22。

### 進め方
1節ずつ、①解説を読む → ②節の中の「確認」を赤シートで隠して答える → ③例題の「解き方」を読み、同じ手順で考える → ④問題を解き、別冊で答え合わせ。間違えたら別冊の「間違えたら戻る」のページを読み直す → ⑤要点を赤シートで隠して言えるか確かめる。間違えた問題は1週間後と1か月後に解き直し、□に印を付けます。章末問題のあとは、別冊の診断表で読み直す節を確かめます。

### 印刷のしかた
- **そのまま印刷**：各 PDF を A4 で印刷します。
- **冊子にする（中綴じ）**：`dist/eg01/booklet/` の PDF を A3 用紙に**両面・短辺とじ**で印刷し、重ねて二つ折りにして中央をホチキスで留めます。左綴じです。本冊は 38 枚と厚いので、ホチキスが届かないときは、A4 版を印刷して左端を綴じてください。
- **ページ順の確認**：`dist/eg01/dummy/` はページ番号だけのダミーです。本番の前に印刷して折り、順に並ぶことを確かめてください。

### 赤シートについて
答えは赤（#FF4B00、カラーユニバーサルデザイン推奨配色セットの赤）で印刷しています。プリンタや用紙によっては赤シートで隠れにくいことがあります。最初に1枚試し刷りして、手持ちの赤シートで隠れるか確かめてください。
