# データ形式（単一データファイル）

1冊の本文・訳・解説・問題・答え・索引・参照ページは、すべて `series/src/<本のID>.yaml` の1ファイルから生成する。冊子どうしの食い違いを防ぐため、同じ内容を2か所に書かない。

## 1. 全体

```yaml
book:            # 書誌（表紙・奥付・柱に使う）
  id: eg01
  series: 高校英語シリーズ
  title: 英文法　関係詞
  edition: 第1版
  date: 2026-12
  publisher: かながわ教材ライブラリ
  license: CC BY 4.0
chapters: [...]  # 章 → 節 → 本文ブロック・例文・要点
problems: [...]  # 節末問題・章末問題・模擬試験の全問
```

## 2. 章と節

```yaml
- id: c1
  title: 関係代名詞の基本
  sections:
  - id: s01                     # 参照用 ID（@s01 で「→ p.○」になる）
    title: 関係代名詞は「名詞の後ろに付く説明」をつくる
    patterns: [P1]              # 05_exam_trends の出題パターン番号
    body:                       # 完全解説book の本文（上から順に組む）
    - h: なぜ関係代名詞が必要なのか     # 項見出し「(1) …」。番号は自動
    - p: 段落の文章。
      notes:                    # 側注（このブロックの横に置く）
      - {kind: 用語, term: 先行詞, text: 説明}
      - {kind: 語注, items: [[next door, 隣に]]}
      - {kind: 注意, text: 説明}
      - {kind: 参照, text: 説明}
    - ex: [e001, e002]          # 例文の表（examples から取る）
    - steps: [問いの文, …]      # 「問1 …」の手順
    - table: {head: [..], rows: [[..], ..]}   # 1列目は見出し列
    - check:                    # 確認問題（答えは赤。赤シートで隠す）
      - {q: "I have a friend [＿] lives in Osaka.", a: who／that}
    examples:
    - id: e001
      en: the book [*that* I read ＿ yesterday]
      ja: 私が昨日読んだ本
      gloss: [[yesterday, 昨日]]      # 省略可。側注の語注になる
    summary:                    # 要点まとめbook（A5・赤シート）の文
    - "先行詞が人で主語が欠けている → {{who}}／{{that}}"
```

## 3. 問題

```yaml
- id: q0001
  sec: s01           # 対応する節（解説の参照ページはここから自動）
  set: 節末          # 節末 / 章末 / 模試
  lv: 1              # 1=★ 2=★★ 3=★★★
  kind: 4択          # 4択 / 正誤 / 整序 / 補充 / 和訳 / 英作 / 読解
  min: 1             # 目安時間（分）
  inst: 指示文       # 同じ指示が続くときは省略可（直前の指示を使う）
  q: 問題文
  choices: [who, whose, which, whom]   # 4択・正誤（正誤は下線部の番号）
  words: [said, she, true, what, was]  # 整序（与える語。自動検査で ans と照合）
  ans: "2"           # 正解（4択・正誤は番号、ほかは文）
  alt: []            # 別解（あれば）
  why: 正解の根拠（1〜3行）
  trap: よくある間違いと、なぜ引っかかるか（1つ）
  ref: s01           # 省略時は sec
```

## 4. 文中の記法

| 記法 | 意味 | 出力 |
|---|---|---|
| `[ … ]` | 関係詞節の範囲 | ［ ］をそのまま表示 |
| `*who*` | 関係詞 | 太字＋下線 |
| `＿` | 節の中で欠けている位置／空所 | 下線の空き |
| `{{…}}` | 赤シートで隠す答え | 赤 #FF4B00 |
| `<<先行詞>>` | 用語の初出（索引に載る） | 太字 |
| `@s03` / `@e012` / `@q2013` | 本書内の参照 | 「→ p.16」「例文12」「問54」 |
| `__…__①` | 下線部と番号（正誤・和訳） | 下線＋丸数字 |
| `**…**` | 強調（1段落1か所まで） | 太字 |

## 5. 自動で決まるもの

- 章・節・項・例文・問題の番号（データの順番から振る。手で書かない）
- 「→ p.○」のページ数（完全解説book を組み終えてから問題集・解答解説を組む）
- 索引（`<<用語>>` と側注の「用語」から集めてページ数を付ける）
- 目次、柱、ノンブル
- 解答用紙の番号と解答解説の番号（問題と同じデータから作るので一致する）
