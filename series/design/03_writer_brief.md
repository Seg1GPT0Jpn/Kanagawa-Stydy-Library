# 執筆者への指示（英文法「関係詞」）

あなたは大学入試（共通テスト＋GMARCH）向け英文法教材の執筆者です。担当する章の本文・例文・確認問題・要点・問題・解答解説を、データファイル（YAML）として書きます。組版は自動で行うので、見た目のことは考えなくてかまいません。

## 1. 最初に読むもの
1. `series/design/02_data_format.md`：データ形式と文中の記法。この形式どおりに書く。
2. `series/src/eg01.yaml` の第1節 `s01`：完成見本。書き方の水準と調子をこれに合わせる。章立て（全19節の ID と題）もこのファイルにある。
3. `series/design/01_design_rules.md` の7章：解説と問題の書き方の規則。
4. `series/research/05_exam_trends.md` の3章と4章：出題パターン P1〜P19、出題形式、受験生の典型的な誤り、★の基準。
5. `series/research/04_ai_tells.md` の「避けること」「やること」チェックリスト。

## 2. 正確さ（最優先）
- 間違った解説は、解説がないより悪い。文法の説明・例文・訳・答えを、1つずつ確かめてから書く。
- 「必ず」「〜できない」と言い切るのは、規則に例外がないときだけ。例外があるときは、例外を具体的に書く。書き言葉と話し言葉で違う語法（whom と who、that の使用など）は、その違いを書く。
- 4択・正誤は、正解がただ1つになるように作る。ほかの選択肢が文法的に成り立ってしまわないか、1つずつ文に入れて確かめる。
- 整序は、与えた語だけで正解の文が1通りに決まるようにする。別の並べ方でも正しい文になるなら、`alt` に書くか、問題を作り直す。
- 和訳・英作は `ans` に模範解答を、`alt` に許容する別解を、`why` に採点の要点を書く。
- 自信のない点は、作業の最後に報告する（「確認済み」とは書かない）。

## 3. 著作権
- 例文・問題・長文はすべて自作する。教科書・参考書・問題集・入試問題の文や問題を写さない。よく見る定番の例文（This is the house where I was born. など）も避け、場面・数・固有の物を入れた自分の文にする。
- 実在の人物・企業・学校を、事実と違う形で登場させない。

## 4. 書き方
- 解説は「です・ます」調。「なぜそうなるか」から始め、小学生にも分かる言葉で、内容は省略しない。説明には必ず例文番号を添える（`@e101` のように書くと「例文N」になる）。
- 新しい用語は初出で `<<用語>>` と書き、同じブロックの側注に `{kind: 用語, term: …, yomi: ひらがな, text: …}` を付ける。全節で同じ用語を二度定義しない（s01 で定義済み：関係代名詞、関係詞節、先行詞）。
- 関係代名詞の選び方は、s01 の「3つの問い」（先行詞は人か・節の中で何が欠けているか・コンマがあるか）と、「後ろが完全な文か不完全な文か」の判断に結びつけて説明する。シリーズ全体で同じ判断手順を使う。
- 和訳は「だ・である」の常体。英語例文の中の関係詞節は［ ］、関係詞は `*who*`、節の中の欠けた位置は `＿` で示す。
- 避けること：「〜しましょう！」、理由のない「〜が重要です」、「まとめると」、「〜と言えるでしょう」、「！」、長いダッシュ、太字の多用（1段落1か所まで）、何でも3つ並べること、同じ文末の3回連続、箇条書きでの説明。
- 英語例文：AI多用語（delve, crucial, pivotal, vibrant, tapestry など）を使わない。教訓・説教調の文を避け、日常の具体的な場面（学校、部活、家族、駅、店、天気、旅行、仕事）に、数・時・物を入れる。文の長さは 5〜35 語でばらつかせる。語彙は ★ で CEFR-J A1〜A2、★★ で B1 まで、★★★ で B2 まで。
- 人名は担当章に割り当てた名前から使い、1つの名前を章で4回以上使わない。

## 5. 分量（1節あたり）
- 本文：項見出し 2〜4、段落 4〜8（1段落は 80〜220 字）、例文 4〜8、必要なら表または手順を1つ、確認問題 2〜4 問。完全解説book で 1.5〜2 ページになる量。
- 側注：その節で初めて出る用語の定義、B1 を超える語の語注、よくある誤解の「注意」。
- 要点（summary）：3〜5 文。答えになる語句を `{{…}}` で囲む（赤シートで隠す）。
- 節末問題：6 問（★ 2、★★ 3、★★★ 1 が目安）。
- 章末問題：章全体で 8 問。章内の節を混ぜて出す（交互練習）。`set: 章末`、`sec` は主に関係する節。
- 形式の配分（章全体で）：4択 約30%、正誤 約20%、整序 約20%、読解（短い英文＋4択の内容理解。英文は 60〜100 語）約15%、和訳 約10%、英作・補充 約5%。
- 全問に `why`（正解の根拠 1〜3 行）と `trap`（よくある間違い1つと、なぜ引っかかるか）を書く。`trap` は 05_exam_trends の典型的な誤りを使う。
- `min`（目安時間・分）：4択・正誤 1、整序 2、和訳・英作 3、読解 4 が目安。

## 6. ID
- 例文：第k章は `e{k}01`〜`e{k}99`（第1章は e101〜。e001〜e003 は s01 で使用済み）。
- 問題：第k章は `q{k}001`〜（第1章は q1001〜。q0001〜q0003 は s01 で使用済み）。
- 節 ID・章 ID は eg01.yaml のものを使い、変えない。節の題を変えたいときは、変えずに報告する。

## 7. 出力と検査
- 担当章の内容を `series/src/parts/c{k}.yaml` に書く。形は次のとおり（担当外の節は書かない）。

```yaml
chapters:
- id: c2
  title: 関係副詞
  lead: 章の最初に置く2〜3文の導入（任意）
  sections:
  - id: s07
    title: …（eg01.yaml と同じ）
    patterns: [P5]
    body: [...]
    examples: [...]
    summary: [...]
problems: [...]
```

- 書き終えたら次を実行し、ERROR を 0 にする。WARN は1つずつ読み、直すか、直さない理由を報告する。
  `python3 series/tools/validate.py series/src/eg01.yaml series/src/parts/c{k}.yaml`
- `series/src/eg01.yaml` とほかの章のファイルは編集しない。組版（build.py）は実行しない（ほかの執筆者と同時に動くため）。

## 8. 最後の報告
担当した節、例文数、問題数（形式別・★別）、自信のない点（文法の細部・答えが2つになるおそれのある問題）、変えたかったが変えなかった点を短く報告する。
