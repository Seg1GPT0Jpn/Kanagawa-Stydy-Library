# 追加執筆の指示：例題と問題の増量（超基礎から学ぶ高校英語　第1講【関係詞】）

本書は「塾に通わなくても学べる塾の教材」を目指す。本冊の各節は「解説 → 例題 → 問題 → 要点」の順で、塾の授業のように、説明を読んだらすぐ例題で考え方をなぞり、その場で問題を解く。今回は担当する章の各節に、**例題2問**を書き、**問題（節末）を各節11問**になるまで増やす。

## 最初に読むもの
1. `series/design/03_writer_brief.md`：書き方・正確さ・著作権・YAML の規則（すべてそのまま守る）。
2. `series/design/02_data_format.md`：記法。
3. `series/src/eg01.yaml`：本文と既存の問題（唯一のデータ）。第1節 s01 の `worked:`（例題2問）が見本。担当する節の本文・例文・確認問題・既存の問題を全部読み、重ならないようにする。
4. `series/review/v1/FIX_BRIEF.md` の「全体の方針」1〜6（不完全な文の定義、［ ］、前置詞＋関係代名詞、譲歩の節の時制、that と which、答えが2つある問題を作らない）。
5. 見本の紙面：`series/build/eg01/honsatsu.pdf` の 5〜8 ページ（第1節）。

## 例題（各節2問）
- 形：`worked:` の下に `q`（問題文）、`choices`（4択のときだけ。4つ）、`steps`（解き方の手順 3〜4 個）、`ans`（4択は番号の文字列 "1"〜"4"、ほかは答えの文）、`point`（ポイント 1〜2文）。
- 例題1は ★ の典型、例題2は ★★ で、その節でいちばん間違えやすい点を扱う。
- `steps` は、生徒が毎回同じ順で考えられるように、第1節の「3つの問い」（先行詞は何か → 後ろで何が欠けているか（完全な文か）→ コンマがあるか）や、その節の判断手順に沿って書く。1つの手順は1〜2文。「超基礎から」なので、文の中のどの語を見ればよいかを具体的に示す。
- 例題の文は、本文の例文・確認問題・問題と同じ文にしない（検査で似すぎは WARN になる）。

## 問題（各節 11問になるまで増やす）
- 既存の節末問題の数を数え、11問になるまで足す。足す問題は ★ を中心に（各節の合計で ★ 4〜5、★★ 4〜5、★★★ 1〜2 になるように）。
- 形式は 4択・整序・補充・正誤・和訳を混ぜる。同じ形が5問以上続かないようにする。
- 例題と同じ考え方で解ける問題を、場面と語を変えて繰り返す（塾の「類題」）。
- 全問に why（根拠 1〜3行）と trap（よくある間違い1つと理由）。答えが1つに決まるかを、ほかの選択肢・ほかの並べ方・ほかの直し方を1つずつ当てはめて確かめる。
- 4択の正解の位置は気にしなくてよい（あとで機械でならす）。正誤の下線の誤りの位置は ①〜④ がばらけるようにする。
- ID：第k章の新しい問題は `q{k}201` から（第1章は q1201〜。第1節 s01 の追加分も q1201〜の範囲で、sec は s01）。`set: 節末`。

## 出力
担当章の追加分だけを `series/src/parts/add_c{k}.yaml` に書く。本体 `eg01.yaml` は編集しない（6人が同時に作業するため）。

```yaml
chapters:
- id: c2
  sections:
  - id: s07
    worked:
    - q: ...
      choices: [...]
      steps: [...]
      ans: "2"
      point: ...
  - id: s08
    worked: [...]
problems:
- id: q2201
  sec: s07
  set: 節末
  ...
```

## 検査
`python3 series/tools/validate.py series/src/eg01.yaml series/src/parts/add_c{k}.yaml` で ERROR 0。WARN は1つずつ見て直す（「ほぼ同じ」の WARN は必ず直す）。組版（build.py）は実行しない。
