# かながわ教材ライブラリ

中学・高校の授業プリントと問題プリント（PDF）を、教科・単元ごとに閲覧できる静的サイトです。

- `chugaku/` 中学・高校入試（中学の単元パック〈神奈川県公立高校入試形式〉と5教科の入試形式模試）
- `koukou/` 高校の授業・定期テスト（高校の基礎科目の単元パックと練習プリント）
- `hatten/` 高校 発展科目（物理・化学・生物・地学・数学Ⅲ・現代文・古典探究・地理探究・政治経済・英語コミュニケーションⅡⅢ）
- `daigaku/` 大学入試対策（共通テスト対策・二次試験対策）

各単元パックは、授業プリント（教師用・生徒用）と、A基本確認〜D誤答訂正の4段階・60問の問題プリント（解答解説つき）からなります。

## ご注意

- すべての問題は AI が作成し、自動検査（形式・正答の整合・重複・検算）に合格したものです。教科担当者による内容確認はまだ行っていません。授業や配布に使う前に内容を確認してください。
- 入試形式の教材は出題形式にならったオリジナル問題で、実際の入試問題ではありません。資料中の統計は、明記したものを除き架空の資料です。

## 公開方法

GitHub の Settings → Pages で「Deploy from a branch」・`main`・`/ (root)` を選ぶと、このリポジトリがそのままサイトとして公開されます。
